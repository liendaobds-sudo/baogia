# So sánh chất liệu in ấn — Bảng tra chi tiết

## Couche theo định lượng (gsm)

| Định lượng | Độ dày (~) | Cảm giác tay          | Ứng dụng chính                                |
| ---------- | ---------- | --------------------- | --------------------------------------------- |
| 90gsm      | 0.08mm     | Rất mỏng, mềm         | Tờ rơi quảng cáo, insert tạp chí              |
| 120gsm     | 0.11mm     | Mỏng, hơi cứng        | Tờ rơi tiêu chuẩn, ruột catalogue             |
| 150gsm     | 0.14mm     | Vừa phải, cứng cáp    | Flyer cao cấp, poster nhỏ, ruột catalogue dày |
| 170gsm     | 0.16mm     | Dày hơn, cầm chắc tay | Brochure gấp, menu nhà hàng                   |
| 200gsm     | 0.19mm     | Dày, khó gấp          | Bìa brochure, folder, danh thiếp kinh tế      |
| 250gsm     | 0.24mm     | Cứng, không gấp được  | Bìa catalogue, tag sản phẩm                   |
| 300gsm     | 0.30mm     | Rất cứng như bìa      | Danh thiếp tiêu chuẩn, thiệp mời, bìa sách    |
| 350gsm     | 0.35mm     | Cứng như carton mỏng  | Hộp mỹ phẩm, tag luxury                       |

### So sánh phổ biến nhất: Couche 150 vs Couche 200

| Tiêu chí          | Couche 150gsm                 | Couche 200gsm                  |
| ----------------- | ----------------------------- | ------------------------------ |
| Độ dày            | ~0.14mm                       | ~0.19mm                        |
| Cảm giác          | Mỏng vừa, dễ gấp              | Dày, chắc chắn, khó gấp        |
| Ứng dụng tốt nhất | Tờ rơi, flyer, ruột catalogue | Bìa brochure, folder, poster   |
| Có gấp được không | ✅ Có, gấp dễ                  | ⚠️ Phải bẻ lằn (cán rãnh) trước |
| In ảnh            | Tốt                           | Tốt hơn (ít bị thấm)           |
| Khuyến nghị       | In số lượng lớn, tiết kiệm    | Cần sang trọng, ít số lượng    |

### Khi nào chọn gì:
- **Couche 150**: Tờ rơi phát tay, quảng cáo, tờ gấp → **tiết kiệm, thực tế**
- **Couche 200**: Bìa catalogue, folder, danh thiếp kinh tế → **chắc chắn, cao cấp hơn**
- **Couche 300**: Danh thiếp, thiệp mời, bìa sách → **chuẩn mực cho ấn phẩm cứng**

| Bề mặt              | Sáng bóng, phản quang        | Mịn mờ, không phản quang     | Mịn như lụa, hơi bóng |

| Phù hợp             | Catalogue sản phẩm, menu ảnh | Brochure doanh nghiệp, thiệp | Lookbook, tạp chí     |

## Giấy mỹ thuật — So sánh

| Loại            | Đặc điểm                 | Ứng dụng                       |
| --------------- | ------------------------ | ------------------------------ |
| Linen (Dệt)     | Vân dệt chéo, cứng       | Thiệp cưới, danh thiếp VIP     |
| Metallic (Nhũ)  | Ánh kim loại, sang trọng | Thiệp, tag cao cấp, hộp quà    |
| Tracing (Trong) | Bán trong suốt, mờ       | Overlay thiệp, bao bì đặc biệt |
| Cotton          | 100% cotton, mềm mại     | Danh thiếp siêu cao cấp        |
| Conqueror       | Vân giấy cổ điển         | Giấy viết thư, bằng khen       |

### Khi khách hỏi "giấy mỹ thuật" → cần hỏi rõ:
- Mục đích: thiệp cưới, danh thiếp, hay bao bì?
- Muốn vân dệt, ánh kim, hay mịn?
- Ngân sách: trung cấp (linen) hay cao cấp (cotton)?
